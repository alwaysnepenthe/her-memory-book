# 点点日记 · Paw Journal

**一本保存在自己电脑上的宠物记录册，记录成长，也收藏可爱的日常。**

「点点日记」是一个温馨的宠物档案与片刻记录网站。你可以为一只宠物建立基础档案，按日期记录体重、日常照片和视频，也可以把某个让你微笑的片刻写进片刻集。

它面向一起成长的日常，也可以补记过去的生活点滴。你不必等到某个特别的日子才记录，一句话、一张照片就可以成为一页片刻。

目前为 **V0.4 公开发布版**：纯前端、无账号系统、无后端数据库，数据保存在使用者自己的浏览器中。

## 视觉风格

页面使用马卡龙色系的薄荷绿、蜜桃粉、淡紫与奶油色，配合花卉、藤蔓、细金线和多层拱形相框。装饰构图参考穆夏与新艺术风格，宠物形象使用用户上传的真实照片。

## 现在可以做什么

### 1. 序章：一本记录册的封面

- 展示宠物照片、名字与写给它的寄语。
- 快速进入成长记录和暖心片刻。
- 显示已收藏的成长时刻与片刻数量。
- 第一次打开没有虚构的成长记录；可以从自己的第一个故事开始。

### 2. 宠物档案：记录它独一无二的模样

独立的宠物档案页面包含：

| 分类 | 可记录的信息 |
| --- | --- |
| 基本信息 | 名字、昵称、宠物种类、品种、性别、毛色与外貌 |
| 相遇的起点 | 出生日期、出生地点 / 地址、到家日期 |
| 性格与日常 | 性格和小习惯、喜欢的东西、其他资料 |
| 日常封面 | 档案照片、写给宠物的一句话 |

- 名字必填，其余资料可以留空，不确定的内容不需要编造。
- 支持上传自己的档案照片，保存后同步展示在序章与档案卡。
- 支持撤销尚未保存的修改。
- 校验出生日期与到家日期，避免到家日期早于生日。

### 3. 成长手账：像翻书一样记录每一个变化

从首页点击「成长记录」或「翻开成长手账」，会先看到一本有对称植物纹样、中央嵌入宠物照片的书。点击封面打开手账，每条记录占一组左右书页：左侧是日期、体重和文字，右侧贴照片或直接播放视频。

每条记录可以包含：日期、标题、体重（kg，可选）、文字、多张照片和视频。

- 新建、查看、编辑、删除记录。
- 按月份筛选，按标题或文字搜索。
- 按日期从最近或最早排序。
- 上一页 / 下一页、页码与键盘 ← → 翻页，翻页带纸张旋转效果。
- 每页展示对应记录的体重；文字和多媒体较多时可以在页内滚动。
- 翻页、合上手账、切换栏目或打开编辑窗口时暂停书页中的视频。
- 支持减少动态效果的系统偏好。
- 展开查看完整文字、大图与视频。

体重功能用于保存事实，不提供健康诊断或医疗建议。

### 4. 日常片刻：留下柔软的瞬间

片刻集使用照片卡片展示日常故事，例如第一次靠着你睡着、一起晒太阳的午后，或某次可爱的举动。

- 记录日期、标题、文字、照片与视频。
- 支持仅有文字的片刻。
- 支持月份筛选、文字搜索、排序和编辑。
- 删除前会再次确认。

### 5. 灵感手账与照片长廊

- 尚无真实成长记录时，可以直接翻阅 「灵感手账」中的 8 条预设记录。
- 演示日期、体重和故事都是模拟数据；演示视频由静态图片缓慢推近制作，**不是宠物真实录像**。
- 使用「我的记录 / 灵感手账」切换；演示数据不进入数据库、不计入真实记录数量，也不进入备份。
- 首页照片区域为一行自动左右往返滚动的长廊，支持暂停、鼠标左侧悬停向左、右侧悬停向右、键盘聚焦暂停和手动横向滚动。
- 公开版从用户的档案照和记录照片中整理长廊；没有个人照片时保持隐藏。

### 6. 本地保存与完整备份

- 使用 **IndexedDB** 保存宠物档案、成长记录、片刻与媒体内容。
- 只有数据库提交成功后，页面才提示保存成功。
- 导出 JSON 备份，包含档案照片、记录文字和记录中的照片 / 视频。
- 导入前校验格式并预览新增、重复记录数量。
- 同编号的记录会跳过，避免重复导入或覆盖现有记录。
- 可以选择是否使用备份中的宠物档案；勾选后会替换当前档案。
- 导入在一个数据库事务中执行，失败时不会只写入一部分。

## 开始使用

### 方式一：直接打开源码版

1. 在 GitHub 点击 **Code → Download ZIP**。
2. 将压缩包**完整解压**到一个固定文件夹。
3. 用 Edge 或 Chrome 打开文件夹中的 `index.html`。
4. 进入「宠物档案」，上传照片并填写资料，然后开始添加记录。

无需安装依赖即可打开网页。请保留同目录中的脚本、样式和 `assets` 文件夹；不要只从 ZIP 中拖出 `index.html`。

不同浏览器对 `file://` 页面的本地存储支持可能不同。如果无法保存，推荐使用下面的本地服务方式。

### 方式二：运行本地服务

建议使用 **Node.js 22.22.2（22.x）、24.15.0（24.x）或 26+**，没有运行时第三方依赖：

```bash
git clone https://github.com/alwaysnepenthe/her-memory-book.git
cd her-memory-book
npm run dev
```

在浏览器打开终端显示的地址，默认是 `http://127.0.0.1:4173`。服务只监听本机地址。

请固定使用同一个浏览器和地址：`localhost`、`127.0.0.1`、不同端口、以及本地文件模式并不共享同一份浏览器存储。

### 方式三：构建单文件版

```bash
npm run build
```

生成 `dist/paw-journal.html`，脚本、样式和花园装饰图均已内嵌。把这个 HTML 文件保存到固定位置，再用浏览器打开即可，不需要额外素材文件。

构建不会读取或打包浏览器里已经保存的日常数据。需要迁移数据时，请在网站中导出 JSON 备份。

## 支持的媒体与容量

| 内容 | 限制 |
| --- | --- |
| 档案照片 | JPG、PNG、WebP、GIF；最大 8 MB |
| 记录附件数量 | 每条记录最多 12 个 |
| 单个记录附件 | 最大 50 MB |
| 一条记录的附件合计 | 最大 160 MB |
| 记录照片 | JPG、PNG、WebP、GIF |
| 记录视频 | MP4、WebM、MOV |
| 备份导入文件 | 最大 512 MB |

视频能否播放取决于浏览器与视频编码，推荐 MP4 / H.264。遇到无法播放的编码，可以下载保存的原视频查看。网站不提供视频转码或压缩。

大文件会占用浏览器配额和内存。媒体以 Data URL 保存，比原文件通常约大三分之一；实际可保存总量取决于浏览器、磁盘空间和设备。JSON 备份也会随之增大，当前版本更适合轻量记录。

## 数据在哪里？如何避免丢失？

**公开仓库不等于公开你的记录册内容。** 本项目没有把用户记录上传到 GitHub 或其他服务器的功能。

- 公共源码不包含原作者的私人宠物照片、出生地址、日常记录或备份文件。
- 上传是将所选文件读入本机浏览器，应用代码不会将这些内容发送到外部服务。
- 源码没有分析统计、追踪脚本、外部字体或运行时 CDN 依赖。
- 数据保存在当前浏览器的当前来源下，并不会写回 HTML 文件。
- 清理网站数据、无痕窗口结束、更换浏览器、改变来源地址，都可能使原记录无法访问。
- 请定期使用「相册与备份 → 导出完整备份」，并确认下载的 JSON 已保存。
- 备份是包含原始内容的普通 JSON，**没有加密**，请按个人文件保管，不要提交到公开仓库。

本版本使用数据库 `her-memory-book-public-v1`。为避免混入开发环境数据，它与早期私人原型的数据库独立；如需迁移，请从旧版导出备份后在这里导入。

### 备份兼容性

公开版导出格式版本为 **3**，包含可上传的档案照片。可以导入早期版本 1、2 和当前版本 3。旧版只有名字、寄语时，其余档案字段会保持为空。

同编号记录不会覆盖。如果想用备份里的修改替换已有记录，需要先自行整理，不应把导入当作双向同步工具。

## 技术结构

```text
her-memory-book/
├── index.html                 # 页面、表单与弹窗
├── style.css                  # 马卡龙花园主题与响应式布局
├── app.js                     # 界面交互、IndexedDB、媒体与备份
├── core.js                    # 数据校验、档案与备份格式、筛选
├── journal.js                 # 封面、翻页、演示记录与照片滚动
├── seed.js                    # 公开版空白数据与封面占位图
├── assets/
│   ├── macaron-garden-v03.png # AI 生成的植物装饰图
│   ├── journal-cover.png      # 对称新艺术植物封面
│   └── demo-journal.mp4       # 静态图片制作的预设片段
├── scripts/
│   ├── build.cjs              # 无第三方依赖的单文件构建
│   └── serve.cjs              # 仅监听本机的开发静态服务
├── tests/
│   └── app.test.cjs           # 数据与界面逻辑检查
├── docs/artwork.md            # 素材生成说明
└── package.json
```

前端使用原生 HTML、CSS、JavaScript。没有框架、云 API、账号系统或服务器端业务代码。IndexedDB 事务用于保证本地写入的完整性；用户文字按文本渲染。

## 开发与检查

网页运行和构建无需安装依赖。执行测试需要安装开发依赖：

```bash
npm ci
npm test
npm run build
```

开发依赖要求 Node.js 22.22.2（22.x）、24.15.0（24.x）或 26+。测试使用 Node.js、jsdom 和 fake-indexeddb，检查空白启动、档案照片与资料保存、记录 CRUD、筛选、备份恢复、旧数据兼容、输入校验，以及双向翻页、首尾边界、演示数据隔离和照片滚动暂停。

这些测试**不能替代真实浏览器验收**。目前尚未完成跨浏览器视觉检查、真实视频编码播放和下载界面自动化验证。手机布局有适配，但主要使用场景仍是电脑浏览器。

## 当前边界与后续方向

当前版本一次管理一只宠物；尚未提供多宠物切换、云同步、多人协作、账号登录、加密备份、自动备份、医疗档案、提醒通知或独立桌面安装包。

它是一款宠物日常记录网站，当前不包含互动小猫动画、抚摸、呼噜音效或三维宠物还原。这些属于更早原型的探索，并不在本次公开版中。

后续可以围绕多宠物支持、更方便的备份、照片整理、打印记录册和媒体优化继续迭代。以上是可扩展方向，不代表已实现。

### V0.5 交互更新

网站标题跟随宠物档案中的名字，例如「点点日记」。序章照片缓慢自动往返滚动，提供暂停按钮；鼠标位于照片区域左半边向左滚动，右半边向右滚动，不显示滚动条。成长手账加入开书与纸张翻页动画，尊重系统减少动态效果设置。

打开手账后可点击「编辑本页」，修改日期、文字、体重和附件。编辑已有记录会更新原记录；编辑灵感手账并保存后，才会加入个人成长记录。未保存的灵感内容不会进入备份。

### V0.6 双模式成长记录

成长记录顶部可选择「翻页手账」或「网页记录」，浏览器会记住展示偏好。两种视图共享记录、筛选、附件与编辑入口，切换不会复制或改变记录。网页模式连续展开所有符合筛选的记录，支持照片查看与视频播放。

书页加入新艺术风格的对称植物纹样：藤蔓曲线、粉色花瓣、鼠尾草绿叶片与细金线。开书动画约 1.4 秒，翻页约 1.2 秒，包含纸张绕书脊旋转、露出下一页、轻微弯曲与明暗变化。可用「翻页效果」选择柔和动画或静态切换；初始设置尊重系统减少动态效果偏好，也可手动开启。

灵感手账新增窗边肖像、三图拼贴、纯文字小信、照片与视频混排四条内容，共 8 条记录（16 个书页面），可在两种展示模式下查看。

### V0.7 细线植物边框与柔性翻页

边框改用疏朗的淡紫鸢尾、细藤蔓和浅香槟色线条，留出更多阅读空间。翻页使用完整的单张纸面，仅外侧页脚轻微卷起，不再分段弯曲；动画中只改变变换与光影透明度，取消中途重建整页。功能测试验证前后翻页、动画中节点稳定、视图切换与编辑保存；实际设备帧率尚未测量。
